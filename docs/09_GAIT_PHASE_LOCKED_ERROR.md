# 歩行位相ロック誤差 — 発見の経緯と解説

**作成**: 2026-07-19
**関連**: [`08_GT_FREE_CHEATSHEET_MODEL.md`](08_GT_FREE_CHEATSHEET_MODEL.md)（発見の実験本体）、
[`07_UV_PSEUDO_WORLD_CORRECTION.md`](07_UV_PSEUDO_WORLD_CORRECTION.md)（bin+ARIMA 分解との整合）

GT フリーモデルの別カメラ検証（docs/08）で得られた最重要知見
「**MediaPipe の系統誤差は視方位ではなく歩行位相にロックしている**」の詳細解説。

---

## 1. 歩行位相ロックとは何か

「系統誤差（角度ずれの波形）が、**何を横軸にすると同じ形になるか**」という問い。
候補は 2 つ:

- **視方位ロック**: 誤差は「カメラが被写体をどの角度から見ているか（φ）」で決まる
- **歩行位相ロック**: 誤差は「歩行動作のどの瞬間か（接地・振り出し等）」で決まる

検証の結果、**膝の誤差は後者**。MediaPipe が膝で失敗するのは
「この方向から見たとき」ではなく「**脚がこの姿勢になったとき**」。

## 2. 発見の経緯（失敗が出発点）

カンニングペーパー（角度バイアス表）を当初は相対視方位 φ で索引した。
結果は奇妙な非対称:

| | φ 索引での改善 |
|---|---|
| 肘 | 61〜73% ✅ |
| 膝 | **−5〜0%** ❌ |

切り分けると「表が間違っている」のではなかった:

- 較正カメラ上（in-sample）では膝も 15°→6.3° と効く
- 誤差の**平均値**は検証カメラに正しく転移（例: L膝 表 6.8° vs 実測 8.3°）
- 合わないのは誤差の「波」の部分（std 約 20°）

**ラグ解析**（表のバイアス波形を ±10 フレームずらしながら実測誤差との相関を計算）:

```
L_KNEE: ラグ 0 で相関 0.33  →  ラグ −8 で相関 0.81
R_KNEE: ラグ 0 で相関 0.64  →  ラグ −6 で相関 0.83
```

**波形自体はほぼ同じで、6〜8 フレームずれているだけ**だった。

## 3. なぜ「8 フレーム」なのか — 幾何との一致

2 台のカメラの違いは、検証カメラが歩行方向（Z 軸）に **+0.4 m** ずれていること。
被写体は Z 軸に沿って約 1.4 m/s で歩くため、「カメラ正面（φ=0）を通過する瞬間」は

```
0.4 m ÷ 1.4 m/s × 30 fps ≈ 8.5 フレーム
```

だけ遅れる。観測されたずれ（6〜8 フレーム）と一致する。

- 誤差が**視方位ロック**なら → 検証カメラでも誤差は φ に張り付き、φ 索引が効くはず
- 実際は誤差が**歩行の時刻に張り付いたまま動かず** → φ 索引の側が 8 フレームずれて空振り

カメラをずらしたことで 2 つの仮説が異なる予言をする**自然実験**が成立し、
「誤差は視方位の関数」という仮説が実験的に棄却された。

## 4. なぜ膝は位相ロックで、肘は φ でも効いたのか

誤差の中身（スペクトル）の違い:

| | 誤差の支配成分 | 8 フレームずれの影響 | φ 索引の結果 |
|---|---|---|---|
| 肘 | ゆっくり変わる大バイアス（−20〜−50°） | ほぼ同じ値を引ける | 61〜73% 改善 |
| 膝 | 歩行周期（約 30 フレーム）で振動する波（±20°） | 波の約 1/4 周期ずれ → 逆符号を引きかねない | 効果ゼロ |

物理的解釈: 膝の誤差源は単眼深度の曖昧性による「前後の脚の取り違え・奥行き誇張」で、
**脚が交差する瞬間・振り出しの瞬間**という歩容イベントに紐づいて発生する。
どの角度から見ているかは（真横近傍では）二次的。

## 5. 解決: 索引を「進行位置 z」に変更

歩行位相そのものは直接測れないが、**同一歩行動作なら「歩き始めから何 m 進んだか」と
歩行位相は 1 対 1**。進行位置 ẑ(t) は UV 復元（docs/07 の腰軌跡復元）から
**GT なしで推定できる**（検証カメラで誤差 平均 3.3 cm ≈ 1 フレーム以下）。

索引を φ → ẑ に変えた効果:

| | φ 索引 | ẑ 索引 |
|---|---|---|
| L_KNEE | −4.9% | **+46.0%** |
| R_KNEE | +0.2% | **+42.2%** |
| L_ELBOW | +73.1% | **+78.2%** |
| R_ELBOW | +61.4% | **+71.4%** |

## 6. 論文への含意

Model 4S の「視点ビン」思想の適用範囲が明確になった:

- 視点ビンは誤差の**平均レベル**（ビン定数バイアス）には正しい索引
  （実際、平均は φ 索引でも転移していた）
- **時間変動する誤差成分**の索引としては歩行位相が支配的

→ 補正は「**視点で決まる定数 + 位相で決まる波**」の 2 階建てで考えるべき。
これは docs/07 §7 の bin+ARIMA 分解（ビン定数 + 滑らかな波 + 白色ノイズ）とも
整合する統一的な描像。

## 7. 限界（docs/08 §5 と共通）

1. ẑ を位相の代理にできるのは**同一歩行動作だから**。任意の歩行への配備には、
   歩行位相そのもの（接地イベント・膝角度の周期性など）を GT フリーで推定する
   位相推定器が次の課題
   → 設計案: [`10_PHASE_EXPLICIT_MODEL_PROPOSAL.md`](10_PHASE_EXPLICIT_MODEL_PROPOSAL.md)
2. 検証したカメラ移動は 0.4 m（同一視点ビン内）。大きく視点が変われば
   ビン定数側が変わるはずで、ビン跨ぎは未検証
