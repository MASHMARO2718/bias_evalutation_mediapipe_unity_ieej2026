## 1. 背景と目的

40_calibration_framework の補正(Model 4S 系)は Phase B の適用時に
「被写体に対するカメラの相対視点」をフォルダ名(カメラ真値位置)から得ており、
実環境では自己完結しない。一方 MediaPipe の出力は:

| 出力 | 持つ情報 | 欠く情報 |
|---|---|---|
| world landmarks (x,y,z) | 体形状(腰中心相対・m) | 大域位置・変位 |
| pose_landmarks (u,v) | 画像平面内の大域位置 | 奥行き・実寸スケール |

そこで **UV 座標から腰位置ベクトル(大域変位)を復元**し、それを土台に
GT を使わない時系列補正を行う。アルゴリズム仕様は
「補正アルゴリズムプロンプト」(prompt_taira.pdf) に基づく。

**前提条件**
1. MediaPipe の誤差はカメラ視線(奥行き)方向に乗りやすい
2. 真横撮影(進行方向 ⊥ 光軸)を想定
3. 擬似ワールド位置ベクトル(UV 大域位置 + MP 相対深度)が構成可能

## 2. アルゴリズム(実装仕様)

### 2.1 擬似ワールド座標系 UV_wod

```
P = s · ( (u−0.5)·W,  −(v−0.5)·H,  z·W )      [m]
```

- (u,v): pose_landmarks 正規化座標(W=1280, H=720)。主点(画像中心)基準に
  中心化(ピンホール X=(u−c_x)·Z/f と整合させるため。定数スケールでは
  並進整合に吸収されるが、可変スケールでは必須)
- Y は画像下向き → 上向きに反転
- z: MP 相対深度(大域奥行き移動は含まない)
- s: 画素→m スケール。**2D(uv のみ)体幹長 + 実効体幹長定数** で決定
  (§5 の検証で確定した方式。`--torso-2d`)

### 2.2 補正手順(PDF 仕様の解釈込み)

1. 進行方向 `D = mean_joints(P(t_last) − P(t_first))`、正規化して D̂
2. `ΔP(t) = P(t) − P(t₀)`(初期フレーム基準と解釈)
3. 平行成分 `r(t) = ΔP(t)·D̂`、直交成分 `ε(t) = ΔP(t) − r(t)D̂`
4. `ε'(t)` = ε の窓幅 W=7 中心移動平均
5. `‖ε(t) − ε'(t)‖ > K·σ(t)` のフレームを除外し ε'(t) で置換 → ε̃(t)
   - σ(t): 窓内移動標準偏差(初期仕様)→ **移動 MAD×1.4826 を推奨**(§4)
6. 補正位置 `P_corr(t) = P(t₀) + r(t)·D̂ + ε̃(t)`
   (「p(t)+ε̃(t)」を平行成分+フィルタ済み直交成分の再合成と解釈)

補正経路は GT フリー。GT はスケール較正定数(被写体体格に相当)と評価のみに使用。

### 2.3 CLI

```bash
# 推奨構成(2D体幹スケール + MAD + K=5)
python 20_pose_correction/run_uv_pseudo_world_correction.py \
    --torso-2d --robust-sigma --k-sigma 5 --outdir results_mad_k5_2d

# 単一カメラ・元仕様(std, K=3)
python 20_pose_correction/run_uv_pseudo_world_correction.py --camera 3.0_1.0_0.0
```

| オプション | 意味 |
|---|---|
| `--robust-sigma` | σ を移動 MAD で推定(自己マスキング回避) |
| `--k-sigma` | 置換閾値 K(既定 3。MAD 併用時は 5 推奨) |
| `--torso-2d` | スケールを uv のみの体幹長で決定(MP z の水増し除去) |
| `--torso-m` | 体幹長事前値(省略時: 3D=0.55 / 2D=0.582) |
| `--per-frame-scale` | フレーム毎スケール(真横ではほぼ無効と実証 §5) |
| `--camera` / `--outdir` / `--max_cameras` | 実行対象・出力先の制御 |

## 3. 主要な検証結果

### 3.1 全 576 カメラ(初期仕様 std K=3)

- 処理 484 台(**92 台は遠方コーナーで MP 検出が 0〜1 フレームのため除外** —
  データ欠損でありアルゴリズムの問題ではない)
- 置換率 19.3%、全体誤差 0.751→0.748 m、置換フレームのみ 0.774→0.755 m

### 3.2 誤差の三層構造(なぜ全体の改善が小さく見えるか)

```
e(t) = 静的オフセット + 滑らかな時変誤差 + スパイク
        (≈定数)          (MA が保存する)     (フィルタの標的)
```

| 成分(補正前・全評価フレーム平均) | 大きさ |
|---|---|
| 全誤差 | 0.751 m |
| 視線(LoS)成分 / 直交成分 | 0.473 / 0.497 m |
| 静的バイアス除去後(動的誤差) | 0.584 m |
| フィルタが実際に除去した量(置換フレームの動的誤差) | 0.621→0.587 m(−3.4 cm) |

移動平均フィルタは定数と滑らか成分を**原理的に**通過させるため、
分母(全誤差)の大半に触れない。評価は「動的誤差・置換フレーム限定」で行うべき。

### 3.3 前提条件 1 の検証 — 3 レベルで結論が異なる

| レベル | 指標 | 結果 |
|---|---|---|
| スパイク成分 | 補正ベクトルの軸配分 | **奥行き 86.9%**(u 2%, v 11%)→ **前提1は強く成立** |
| 誤差全体 | Error·MC の mean \|cos φ\| | 0.539(等方=0.50)→ 弱い。腕 0.58–0.61 > 脚 0.48–0.49 |
| 解釈 | — | 前提1は高周波(スパイク)成分に成立。全体では面内の静的・滑らか成分が支配 |

軸配分は真横 86.4% / 前後 85.4% / 斜め 88.1% と視点によらず一定。

### 3.4 真横カメラの意味

| グループ | D̂ の画像水平成分 / 奥行き成分 | 解釈 |
|---|---|---|
| 真横(Z=0) | 0.999 / 0.048 | **唯一、分解が物理的に正しいレジーム**。r(t)=移動が構造的に奥行きノイズから保護される |
| 前後(N/S) | 0.738 / 0.206 | UV は奥行き移動を観測できず D̂ が破綻。数値上の改善は解釈不能 |

改善「率」は前後の方が大きく見えるが、それはレジーム破綻した信号を強めに
平滑化しているだけ。真横の価値は率ではなく**分解の正当性**。

### 3.5 単一カメラ精査(CapturedFrames_3.0_1.0_0.0)と自己マスキングの発見

- **frame 47 に全身級の MP グリッチ**があり、フィルタが正しく捕捉
  (肩 −57 cm、右足首 −61 cm など、10 関節平均 +17.8 cm 改善)
- 残り 162 置換は境界すれすれで改善 79 vs 悪化 83 の**コイントス**
- **自己マスキング**: 移動標準偏差はスパイク自身で膨らむため、
  「残差/閾値」比が本物(frame 47)も境界も同じ 1.14 になり、K 調整では分離不能

### 3.6 MAD 化(`--robust-sigma`)の効果

| | std K=3 | MAD K=5 |
|---|---|---|
| frame47 の残差/σ 比 | 1.14(区別不能) | **16.6**(通常フレームは 1.9) |
| 置換率(全体) | 19.3% | **8.8%**(介入半減) |
| 1 置換あたり改善 | +1.87 cm | +1.86 cm |
| σ比の情報価値 | なし(全て≈1.1) | **異常度スコアとして機能**(σ比>50 は +10.5 cm/66%改善) |

frame47 級の壊滅的グリッチは全データで稀(σ比>50 は 258,024 行中 47 行)。
K は用途で選ぶ: バランス K=5 / グリッチのみ K≈15–20。

### 3.7 腰軌跡の V 字誤差 — 原因診断とスケール修正(最重要の成果)

腰中心誤差の時系列プロットで、歩行両端 ±1.15 m・中央 0 の V 字を発見。

**仮説の変遷(記録として残す)**
1. ~~透視ドリフト説~~ → フレーム毎スケール(B2)を実装しても不変で棄却。
   真横カメラは光軸奥行きが一定(3.0 m)で、見かけ体幹長の変動は実測 ±4% のみ
2. **確定した原因 = スケールの定数バイアス 2 件**:
   - MP の z が 3D 体幹長の **54%** を水増し → スケールが真値の 56% → 軌跡が 44% 縮む(V 字高さと定量一致)
   - GT 鎖骨基準の事前値 0.523 m は MP ランドマーク定義の「実効体幹長」と別物。
     真横 4 台の実測で **実効値 0.582 m ± 5%**

**修正(`--torso-2d` + 較正定数 0.582 + 主点中心化)の結果(3.0_1.0_0.0)**

| 構成 | 平均誤差 | 最大誤差 |
|---|---|---|
| 旧(3D 体幹スケール) | 0.581 m | 1.174 m |
| 修正(2D 体幹 + 0.582 m) | **0.067 m** | 0.316 m |
| 修正 + MAD K=5 | **0.065 m** | **0.182 m** |

- **UV からの腰軌跡復元が真横・3 m で平均 6.7 cm 精度で成立**(8.7 倍改善)
- 残差の唯一の構造 = frame47 スパイク(0.32 m)を MAD 補正が 0.18 m に切除 —
  スケール誤差を除いた途端、フィルタの価値が全体グラフでも視認可能になった
- プロット: `results_mad_k5/plots/hip_center_error_scale_fix.png`

2. 実効体幹長の被写体・観察側ごと較正(±5% → 数 cm 精度へ)、

   スケール変化(見かけサイズ)由来の奥行き推定か複数カメラが必要
5. この UV 変位復元を Model 4S の Phase B ビン自己選択
   (視点 φ・高さ・距離の自己推定)に接続 — 「GT 前提の補正」批判への回答

   ARIMA 係数を較正し対象カメラへ適用。通れば GT フリー深度補正が成立

### 7.3 鏡映問題の発見(重要)

視点ビン(E × Y=1.0)の他カメラ 10 台から Model 4S 流のアウトオブサンプル
バイアスを構築したところ、**符号が反転**して失敗(L: 他カメラ平均 −0.427 vs
対象実測 +0.893)。

原因: 位置合わせ(§2)の**鏡映候補選択がカメラごとに独立**であり、鏡映の
有無によって MP 奥行き誤差が世界座標 ±X のどちらへ写るかが反転するため。
ビン内 10 台のうち対象カメラと同じ鏡映フラグは 1 台のみだった。

> **教訓**: 4S 系バイアス補正を深度に適用するには、深度の左右曖昧性
> (handedness)を決定論的に解消する前処理が必須。

同一鏡映フラグのカメラに限定してバイアスを再構築すると正常化:
L +0.859(対象実測 +0.893 と 3 cm 差)/ R −0.475(同 −0.411)—
**視点ビン内でバイアスが汎化する**ことの実証でもある。

### 7.7 配備への条件(数字の読み方)

§7.4–7.6 の数字は以下の条件付きで読むこと:

1. **ARIMA は GT 誤差系列への in-sample フィット** — 現状は
   「較正済み係数を配備した場合の上限性能」。実運用形は
   Phase A でビンごとに係数較正 → Phase B で係数固定フィルタとして適用。
   汎化検証は「ビン内別カメラで較正 → 対象カメラへ適用」で可能(未実施)
2. **鏡映(深度左右曖昧性)の決定論的解消が前提**(§7.3)
3. 依存追加: `statsmodels`(ARIMA)。requirements.txt 未反映

## 8. アブストラクト草稿(2026-07-19 時点の成果の要約)

**和文**: 単眼姿勢推定器 MediaPipe Pose の 3 次元出力は腰中心の相対座標であり、
身体の大域変位を含まないうえ、誤差がカメラ視線(奥行き)方向に集中するという
構造的制約を持つ。本研究では、進行方向に対して真横から撮影する条件の下、
画像正規化座標(UV)が保持する大域位置情報を利用して腰位置ベクトルを復元し、
正解データ(GT)を用いない誤差補正を行う枠組みを提案・検証した。まず、
スケール決定における推定深度成分の混入(体幹長の 5 割超)と体節定義の不一致が
もたらす軌跡の系統的収縮(約 44%)を同定し、2 次元体幹長と被写体固有の実効
体幹長定数による較正でこれを解消した結果、Unity シミュレーション(576 視点)の
真横カメラ(距離 3 m)において腰軌跡を平均誤差 6.7 cm で復元した。次に、
進行方向への直交分解と移動 MAD による頑健な外れ値検出を用いた時系列フィルタを
構成し、補正エネルギーの 87% が視線方向に集中することを確認して「誤差は奥行きに
乗る」という前提を定量的に裏付けた。さらに、残存する奥行き誤差が視点ビン別の
符号付き定数バイアスと低次 ARIMA でモデル化可能な滑らかな変動に分解できることを
示し、両者の減算により膝関節の奥行き誤差を 82〜90%(0.89 m → 0.09 m)、
膝角度 MAE を 26〜43%(15.6° → 8.9°)低減した。本結果は、視点情報の自己推定に
基づく実環境配備可能な姿勢補正への道筋を与える。
