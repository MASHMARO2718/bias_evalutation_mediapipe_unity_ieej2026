# 06 Signed Bias 補正分析レポート

**生成日**: 2026-07-14  
**スクリプト**: `scripts/signed_bias_eval.py`, `scripts/gen_signed_figs.py`  
**データ**: `32_direction_detection/output/processed_data/detailed_results.csv`

---

## 概要

`detailed_results.csv`（259,356行, 505カメラ, 12関節）の符号付き方向角誤差を使い、
Signed Bias 補正と Unsigned Bias 補正の効果を比較した。

評価指標: **mean |Δθ|**（方位角方向の平均絶対誤差）  
補正モデル:
| ID | 手法 | バイアス推定 |
|----|------|------------|
| M4S | 視点ビン（8方向×4高さ） | 符号付き mean(Δθ) |
| M4U | 視点ビン（同上） | 符号なし mean(\|Δθ\|) |
| M2S | 関節別定数 | 符号付き mean(Δθ) |
| M2U | 関節別定数 | 符号なし mean(\|Δθ\|) |

---

## メインの結果（λ=1.0）

| モデル | 補正前 |Δθ| | 補正後 |Δθ| | 改善率 | 既知/未知 |
|--------|------------|------------|--------|---------|
| **M4S（Signed ViewBin）** | 34.7° | **9.8°** | **+71.8%** | 既知 |
| **M4S（Signed ViewBin）** | 39.1° | **10.5°** | **+73.1%** | 未知(Y=2.0) |
| M4U（Unsigned ViewBin） | 34.7° | 47.4° | −36.6%（過補正） | 既知 |
| M2S（Signed JointConst） | 34.7° | 21.7° | +37.4% | 既知 |
| M2U（Unsigned JointConst） | 34.7° | 50.4° | −45.3%（過補正） | 既知 |

**主な知見**:
1. **符号なし補正（M4U, M2U）は一貫して過補正** → 補正後の誤差が補正前より大きい
2. **符号付き補正（M4S）は71.8%の大幅改善** → 視点ビン分割の効果が最大限発揮される
3. **M2S（関節別定数）も37.4%改善** → 単純な平均でも符号が正しければ有効
4. **未知視点(Y=2.0)でもM4Sは73.1%改善** → ビン分割は未知視点に対しても強く汎化

## λ 感度分析（M4S, 既知視点）

| λ | 補正後 |Δθ| | 改善率 |
|---|------------|--------|
| 0.00 | 34.7° | 0.0% |
| 0.25 | 27.4° | 21.2% |
| 0.50 | 20.2° | 41.7% |
| 0.75 | 13.8° | 60.2% |
| **1.00** | **9.8°** | **71.8%** |
| 1.25 | 13.2° | 61.9% |
| 1.50 | 19.9° | 42.6% |

**→ 最適補正強度は λ=1.0 と確認。** over-correction は λ>1 で生じる。

## 関節別改善率（M4S, λ=1.0, 既知視点）

| 関節 | 補正前 |Δθ| | 補正後 |Δθ| | 改善率 |
|------|------------|------------|--------|
| L_Elbow | 60.0° | 4.7° | **92.1%** |
| R_Elbow | 60.5° | 5.2° | **91.3%** |
| L_Shoulder | 10.3° | 2.2° | 78.4% |
| R_Shoulder | 9.2° | 1.9° | 78.9% |
| L_Knee | 15.2° | 4.7° | 69.4% |
| R_Knee | 15.9° | 4.4° | 72.3% |
| R_Hip | 62.5° | 30.5° | 51.2% |
| L_Hip | 44.0° | 24.7° | 43.9% |

**Elbow が最も改善**: 元々 ±58° 超の大きなバイアスが方向一貫していたため、
符号付き補正で92%まで除去された。**Hip の改善が低い**のは、
骨盤の非剛体問題（Model 6 の実装が必要）により誤差が方向一貫しないため。
