# docs/ — 設計ドキュメント・分析レポート

このフォルダにはフレームワークの**設計書**と**分析結果のレポート**が格納されています。
実装の背景・意思決定の記録として参照してください。

## ドキュメント一覧

### 設計ドキュメント（初期）

| ファイル | 内容 |
|---------|------|
| `01_MediaPipe Pose 補正モデル・アーキテクチャ仕様.md` | 全補正モデル（Model 1〜7）の数式定義・処理フロー・実装方針 |
| `02_局所線形補正フレームワーク提案.md` | 局所線形モデルの動機・提案手法・期待効果 |

| `04_局所線形性評価の解説.md` | Phase A の局所線形性評価（R²・OLS）の詳細解説 |

### 分析レポート（スクリプト実行後に作成）

| ファイル | 対応スクリプト | 内容 |
|---------|--------------|------|
| `05_linearity_analysis.md` | `experiments/run_evaluation.py` + ダッシュボード | 生データの線形性検証：2次・4次多項式フィット、左右分割分析、谷構造の特定 |
