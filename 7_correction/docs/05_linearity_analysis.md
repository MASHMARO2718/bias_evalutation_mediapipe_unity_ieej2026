# 線形モデル妥当性評価：生データ可視化と多項式フィット分析

**作成日**: 2026-06-21  
**対象データ**: `3_joint_angle_mae/joint_angle_mae_csv/` (4高さ層 × 8方位角ビン, N=576)  
**分析ツール**: `7_correction/dashboard/app.py` → Raw Data タブ

---

## 1. 分析の目的

MediaPipe Pose 補正フレームワークでは，推定誤差 $e$ がカメラパラメータの
**線形関数**で近似できるという「局所線形性仮説」を基盤としている．

$$e \approx \beta_0 + \beta_1 Y + \beta_2 D + \beta_3 \sin\varphi + \beta_4 \cos\varphi + \beta_5 \varepsilon$$

本分析では，補正を一切加えていない生データ（角度 MAE）を各カメラ特徴量に対してプロットし，
**全視点一括（グローバル）での線形モデルが適切か**を検証した．

## 4. 可視化で観察された非線形構造

### 4.1 方位角プロットの谷（U 字型）

生データ散布図（Raw Data タブ）で顕著に観察されたのが，
**方位角 0° 付近（正面）での MAE の谷**である．

```
MAE [°]
 60 |  ●    ●        ●    ●
    | ● ●  ● ●      ● ●  ● ●
 40 |      ●●●●●●●●●
    |           ↑谷
 20 |
    +---------------------------→ azimuth_deg [°]
      -180    -90      0    +90   +180
```

この構造は以下を示している：

- **前後方向（azimuth ≈ 0°, ±180°）** では MAE が低い → 正面・背面のビューではポーズ推定が安定
- **側面方向（azimuth ≈ ±90°）** では MAE が高い → 側面ビューで推定誤差が増大

この U 字型は **1次（線形）** では捉えられず，**4次以上** でようやく部分的に近似可能である．

### 4.2 左右非対称性

方位角の中央（0°）でデータを左右分割してフィットすると，
**左半（azimuth < 0°）と右半（azimuth ≥ 0°）で R² が大きく異なる**関節が多い：

| 関節 | 左-2次 | 左-4次 | 右-2次 | 右-4次 | 非対称性 |
|------|--------|--------|--------|--------|---------|
| L_Shoulder | 0.218 | **0.384** | 0.587 | **0.617** | 右 >> 左 |
| R_Shoulder | 0.637 | **0.701** | 0.581 | **0.685** | ほぼ対称 |
| L_Elbow | 0.635 | **0.685** | 0.639 | **0.685** | ほぼ対称 |
| R_Elbow | 0.663 | **0.708** | 0.138 | 0.142 | **左 >> 右** |
| L_Hip | 0.399 | **0.448** | 0.358 | 0.396 | やや左優位 |
| R_Hip | 0.508 | **0.508** | 0.100 | 0.218 | **左 >> 右** |
| L_Knee | 0.379 | **0.415** | 0.064 | 0.117 | **左 >> 右** |
| R_Knee | 0.078 | 0.082 | 0.329 | **0.353** | 右 >> 左 |

> **解釈**: 身体の左右対称性の破れが視点方向への依存性に現れている．
> L 系関節は特定の方位角半平面で多項式フィットが機能しやすく，
> R 系関節は反対の半平面で機能する傾向がある．
> これは MediaPipe の骨格推定モデルの左右非対称な訓練バイアスに起因する可能性がある．

## 5. グローバル線形モデルが失敗する理由

### 5.1 空間的な非均質性

誤差分布は視点空間全体で **均質ではない**．方位角の正面・側面・背面でまったく異なる
構造を持つため，単一の線形式はいずれのセグメントにも適合できない．

### 5.2 相互作用効果の欠如

線形モデルでは `sin_azimuth`・`cos_azimuth`・`camera_y` などの **交互作用項がない**．
実際には「側面×高い視点」で誤差が特に増大するなど，特徴量間の積の効果が存在する可能性がある．

### 5.3 バイアスの非線形性と左右非対称

グローバル R² が Hip 関節（0.56〜0.63）は比較的高いが，Shoulder・Elbow は 0.01 未満である．
関節ごとに誤差メカニズムが異なり，**単一の特徴量セットで全関節を説明するのは困難**である．

## 6. 局所線形モデルの正当性

グローバルモデルの失敗にもかかわらず，`local_linear_fits_az8.csv` に記録された
**ビン内の局所線形フィット**では高い R² が得られている：

| ビン (height×azimuth) | 関節 | 局所 R² |
|----------------------|------|---------|
| (0, 0) = Y=0.5 × N | L_Shoulder | **0.901** |
| (0, 0) | L_Elbow | **0.911** |
| (0, 0) | L_Hip | **0.907** |
| (0, 1) = Y=0.5 × NE | L_Shoulder | **0.943** |
| (0, 2) = Y=0.5 × E | L_Shoulder | **0.956** |

> **核心的知見**: **視点空間を方位角×高さビンに分割することで，各局所領域内では
> 線形モデルが非常に高い精度（R² > 0.9）で誤差を説明できる**．
> これは「局所線形性仮説」が正しいことを強く支持する．

グローバル線形モデルの R² が極めて低い（< 0.01）のに対して，
局所モデルが R² > 0.9 を達成するという対比は，
**ビン分割の設計が補正精度の鍵**であることを明確に示している．

---

## 7. 多項式次数の選択に関する考察

### 7.1 2次 vs 4次の改善量

グローバルスコープで見ると，2次から4次への改善はケースバイケースである：

- **Elbow 系**: 2次→4次で R² が 0.26→0.57（L_Elbow）と大幅に改善
- **Hip 系**: 2次→4次の改善は 0.03〜0.04 程度と小さい
- **Knee 系**: 4次でも R² < 0.18 と限界あり

### 7.2 過学習リスク

4次多項式はデータ点数が少ないビン（n < 10）では過学習が懸念される．
576 行のグローバルデータには十分なサンプルがあるが，
**個別ビン（平均 n ≈ 18）では 2次が安全な選択肢**となる．

### 7.3 代替アーキテクチャの示唆

| アプローチ | 利点 | 欠点 |
|-----------|------|------|
| グローバル線形 | シンプル・解釈容易 | R² < 0.01，実用不可 |
| グローバル 4次多項式 | 中程度の精度 | 関節依存・過学習リスク |
| 局所線形（ビン分割）| R² > 0.9，実装済み | ビン数のハイパーパラメータ調整が必要 |
| 左右分割 × 高次多項式 | 非対称性を捉える | ビン境界での不連続が生じる |

---

## 8. 結論

1. **グローバル線形モデルは方位角の U 字型非線形構造により R² ≈ 0 となり不適切**である．
   特に L_Shoulder（R²=0.002），L_Elbow（R²=0.004）で顕著である．

2. **4次多項式はグローバルスコープでの改善をもたらす**（L_Elbow: 0.004→0.57）が，
   実用的な補正精度（R² > 0.9）には到達しない．

3. **中央分割フィットは方位角の左右非対称性を定量化**する有用な手法であり，
   R 系関節の一部（R_Elbow, R_Hip, L_Knee）では左右で R² が著しく異なる．

4. **局所線形モデル（方位角×高さビン分割）はこれらの問題を根本的に回避**し，
   R² > 0.9 を達成する．ビン分割が「暗黙的に非線形性を分割統治している」ことが確認された．

5. **最優先の改善策は，より細かい方位角ビン数（n_azimuth > 8）の探索**であり，
   Grid Search の結果と合わせて最適ハイパーパラメータを決定することが推奨される．

## 付録: 分析スクリプト

本分析は `7_correction/dashboard/app.py` の **Raw Data タブ** で再現可能．

- **関節セレクタ**: 8 関節を個別に確認
- **高さ層フィルタ**: 特定の高さ層に絞り込み
- **サンプリング**: 全データ / 50% / 25%
- **分割位置**: x 軸の中央値で自動計算（方位角は 0°）
- **フィット色**:
  - 🟠 左半-2次（オレンジ破線）
  - 🔴 左半-4次（赤点線）
  - 🔵 右半-2次（青破線）
  - 🟢 右半-4次（緑点線）
